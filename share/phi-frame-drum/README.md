# PHI frame drum

PHI's owner's own frame drum recordings, "FrameDrumSamples7Aug19" (August 2019), as the sounds of
PHI frame drum (`Source/sampler/PhiFrameDrum.h`, docs/phi-frame-drum.md). `README-2019.txt` is the
recordings' own notes: performer, microphone, interface, EBU R 128 loudness, 120 BPM loops, and
their licence, CC BY-SA 4.0.

The files are the 2019 ones, renamed:

| Here | 2019 |
|---|---|
| `bass-1`, `bass-2`, `bass-5` to `bass-8` | OneShots-FD `01_Bass1`, `02_Bass2`, `05_Bass` to `08_Bass` |
| `rimshot-1` to `-4` | `09_Rimshot1` to `12_Rimshot4` |
| `finger-snap-1` to `-3` | `13_FingerSnap1` to `15_FingerSnap3` |
| `side-knock-1` to `-5` | `16_SideKnock1` to `20_SideKnock5` |
| `flat-hand-1` to `-3` | `21_FlatHand1` to `23_FlatHand3` |
| `hand-sweep-1` to `-7` | `24_HandSweep1` to `30_HandSweep7` |
| `phrase-*` | QuarterNotePhrases-FD `01` to `09` |
| `loop-fives-*`, `loop-sevens-*` | Fives-FD, Sevens-FD |
| `loop-chiftetelli`, `loop-maqsum-1`/`-2`, `loop-baladi-1`/`-2`/`-4` | Fours&Eights-FD `01_chiftitelli`, `02`/`03_mousmodi`, `04`/`05`/`07_balladi` |

Left out as the same recording as another: `03_Bass3` and `04_Bass4` (`02_Bass2`), `02-Bass2` (a
stereo copy of `02_Bass2`), and `06_balladi3` (`05_balladi2`).
