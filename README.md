# Φ PHI

A keyboard-first audio editor and mastering suite for Linux, combining the best of
Adobe Audition, Sound Forge and WaveLab. Optimized for Arch Linux, Omarchy and Hyprland.

PHI is written with the Greek letter Φ (phi) in its logo and window title, and as plain
`PHI` / `phi` wherever only ASCII will do (the program, its folders, window class and file
names). It was called PHINYX before; its first start under the new name moves the old
`~/.config/phinyx`, `~/.local/share/phinyx` and `~/.cache/phinyx` folders to `phi`, and
projects, albums, batches and chains saved by PHINYX open as before.

Status: Phase 2 complete: a usable editor with markers, meters, spectrogram, themes, a plugin Master Section and a spectral repair lab. Not yet tested on real audio hardware. See the full plan in [docs/plan.md](docs/plan.md).

Built with a Qt 6 interface (native Wayland) on top of a JUCE 8 audio engine.

## What works now
- Open WAV/AIFF/FLAC/Ogg/MP3 (`Ctrl+O`, or pass a file on the command line); save as WAV/FLAC/AIFF/Ogg (`Ctrl+S`, `Ctrl+Shift+S`) with bit depth and TPDF dither. WAV markers (cue points and regions) are kept.
- Playback through ALSA or JACK/PipeWire (`Space`), cursor movement (`Left`/`Right`, `Ctrl+Left`/`Ctrl+Right`, `J`/`L`, `Home`/`End`), zoom (`+`/`-`, `Ctrl+0`, `Ctrl+E` to the selection, `Ctrl`+mouse wheel)
- Transport bar across the top: Go to Start, Play/Pause, Stop, Go to End, Record and Loop as flat symbols, each showing its shortcut when you hover it, and the time as `00:00:00.000`. `Space` pauses where it is; Stop (`K`) goes back to where playback started; Loop (`Ctrl+L`) plays the selection, or the whole file, over and over
- Whole-file overview above the editor (`Ctrl+Alt+O` shows or hides it): the box marks what the editor shows; drag across it to zoom the editor to that stretch, drag the box to move it, drag an edge of the box to zoom, or turn the mouse wheel over it to zoom around the mouse. Double-click moves the cursor
- Find panel on the left (`Ctrl+F`; pressed again it hides the panel), like Ableton Live's browser: one search field finds any process, Nyquist effect, plugin or audio file; the sidebar narrows it to a category, a Selector colour or a folder (Places, Add Folder...). The Selector holds favourites in eight colours, top to bottom Silver, Violet, Indigo, Azure, Emerald, Gold, Saffron and Ruby, and comes in sets, picked with a right-click on the word Selector or on a colour: Favorites (the colour names, the default) and one per activity, Live Performance (FX, PD, ARP, VOX, LD, PR, BA, DR), Mixing, Mastering, Podcast and Chakra. Each set has its own names and its own favourites; F2 or a double-click renames a colour, and the right-click menu also renames the set. Mixer > New Mix from Selector Set starts a mix of 8 tracks with the chosen set's names and colours from the bottom up (for Live Performance, DR on track 1 to FX on track 8). Down from the empty search goes into the sidebar (Selector colours, categories, places) and, after typing, into the results; Right goes from the sidebar to the results, Left back, and Up at the top of a list returns to the search. Enter runs the process, loads the plugin into the first free Master Section slot or opens the file, Tab moves between search, sidebar and results, `1` to `8` give the selected result a Selector colour (`0` clears them), Escape clears the search or returns to the editor. Files and Places are browsed one folder at a time (the header shows where you are, such as "Samples / Breaks / Jungle"): Enter or Right opens a folder, Backspace, Left or the `..` row goes up; typing searches every folder at once. Moving onto a file with the arrow keys, or clicking it, auditions it without opening it (through the meters, after the Master Section); clicking it again or `K` stops
- Time rulers on the overview and the editor that follow the zoom, from hours and minutes down to microseconds; click a ruler to move the cursor
- File details (position, length, selection, format, play state, audio device) along the bottom of the editor, with steady digits so nothing shifts as the numbers change
- Selection by mouse drag, `Shift`+click, `Shift`+arrows/`J`/`L`/`Home`/`End`, `Ctrl+A`; `Esc` clears it
- Tabs: each open file gets its own tab above the waveform, with its own undo history, selection and zoom. `Ctrl+O` opens into a new tab, `Ctrl+Tab`/`Ctrl+Shift+Tab` (or `Ctrl+Page Down`/`Up`) switch tabs, `Ctrl+W` closes one (only when the editor has the keyboard: with a panel focused it closes that panel instead). Copy and paste work between tabs.
- Any channel count, from mono to 5.1, 7.1 and 7.1.4: each lane and meter is labelled with its speaker (L, R, C, LFE, Ls, Rs...), the status bar names the layout, loudness weights the surrounds per ITU-R BS.1770, and the Master Section, render and save keep every channel (surround WAVs carry their speaker layout). Surround files are heard folded down to stereo (centre and surrounds at -3 dB, LFE left out), which suits headphones; Options > Play Surround on Separate Outputs sends each channel to its own output when the device has enough. A plugin that only handles stereo processes the front L/R and its card says "L/R only". Pasting between layouts puts channels in the same positions.
- Record (`Ctrl+R`), like OBS: record what you hear on the desktop (any output, e.g. AirPods or speakers), any input (microphone, audio interface), or just one application (only the browser, only a game). The list updates as devices and apps come and go. Live meters with a clip light (click it to clear), a pre-record buffer that keeps the last few seconds before you pressed Record, and a disk-space estimate. The take goes into a new tab or at the cursor as an undoable edit. `Enter` starts and stops. While recording, a safety copy is written to `~/.cache/phi/recordings`; if PHI closes unexpectedly, the next start offers to recover it into `~/Music/PHI Recovered`. Needs PipeWire (the Arch and Omarchy default).
- Copy to New (`Shift+C`), like Audition and WaveLab: puts the selection (or the whole file) in a new untitled tab, markers included
- Editing: cut/copy/paste/delete (`Ctrl+X`/`C`/`V`, `Del` or `Backspace` on a selection; select by dragging, `Shift`+arrows or `Ctrl+A`, or double-click between two markers to select everything between them), Snap to Zero Crossings (`Ctrl+Alt+Z`, Edit menu) so selection edges land where the wave crosses zero and edits do not click, trim to selection (`Ctrl+T`), insert silence (`Ctrl+Alt+S`)
- Processing (on the selection, or the whole file when nothing is selected): gain (`Ctrl+G`), normalize to peak dBFS or integrated LUFS (`Ctrl+Shift+N`; loudness has presets for Spotify, YouTube, Apple Music, podcasts and broadcast, can match another file's loudness, and can limit the true peak, -1.0 dBTP by default, so turning up does not clip), fade in/out with four curve shapes (`Ctrl+Shift+I`/`O`), reverse (`Ctrl+Shift+R`), invert (`Ctrl+Alt+I`), DC offset removal (`Ctrl+Alt+D`). Stereoize (`Ctrl+Alt+W`) turns mono into stereo (or rebuilds a stereo image) with width, delay and a bass-stays-centred setting; it folds back to exactly the original in mono. Stereoize is also a live effect in the Device Chain (Add plugin, then pick Stereoize under Built-in) with Width, Delay and Bass knobs you can turn while listening; rendering a mono file through it makes the file stereo. Its Φ button for the golden ratio (off by default; Φ Golden on the live effect) widens with four allpasses at the delay, 1/φ, 1/φ² and 1/φ³ of it instead of one delay, so the colour the widening adds is no longer an evenly spaced comb and sounds less pitched; it still folds back exactly in mono, and Mid/Side Width's Generate sides has the same switch. Mid/Side Width (`Alt+Shift+W`, in the Process and Spatial menus) widens or narrows the stereo image by working on the side (what differs between left and right) and leaving the centre alone: width 0 to 200 % (Huge allows 300 % and eases back while the sides go out of phase), Mono below a crossover up to 500 Hz for tight centred bass, Generate sides (width made from the centre above 150 Hz that cancels in mono, so it widens mono sounds too), Air (a side-only high shelf, ±6 dB), Rotation (±45°), Lift (more width on louder moments) and Match level. Its stereo field shows the dots before (grey) and after (colour); drag it sideways for width and up or down to rotate, or use the arrow keys. It reads out the correlation, the mono-sum level and the side against the centre, before and after. Presets, Preview, A/B against the original, and Listen in Stereo, Mono, Side only or Bass. It is also a live effect under Built-in in Add plugin.
- Repair (Phase 2 Part A): in the spectral view (`Shift+D`) a drag selects a box of time and frequency (drag over nearly the whole height for every frequency), or type the band with Frequency Range (`Ctrl+Alt+F`). Auto Heal (`Ctrl+U`) rebuilds the selection from the sound around it, for clicks, coughs, squeaks and phone rings, up to 4 seconds at a time: steady tones carry on through the gap and background noise is refilled at its own level. Spectral Gain (`Ctrl+Alt+G`) turns the box down or up with soft edges, and Delete in a box removes just those frequencies. All of it is undoable and leaves audio outside the box untouched
- Export (`Ctrl+Alt+X`, File menu), like WaveLab's rendering: a list of outputs written in one go, for example a 24-bit WAV, an MP3 320 and an AAC 256 together. Every format FFmpeg can encode on your system is offered (MP3, AAC/M4A, Opus, Ogg Vorbis, FLAC, ALAC, WavPack, TTA, AC-3, E-AC-3, DTS, TrueHD, MP2, WMA, Speex, AMR, GSM, G.711/G.722/G.726, ADPCM, aptX, SBC, Matroska and WebM, W64, CAF, AU and more); formats your FFmpeg lacks are listed greyed. Each output has its own encoder settings, sample rate, bit depth and dither, loudness target (streaming, Apple, podcast, broadcast presets) with a true-peak ceiling, folder, file name pattern (`{filename}`, `{title}`, `{artist}`, `{track}`, `{part}`, `{rate}`, `{bits}`, `{date}`...), what to do when the file exists, metadata template and schemas. Export the whole file, the selection, each region or each part between markers, through the Master Section or not. Preview plays the selection (or 20 seconds from the cursor) encoded in place of your audio, looping; `A` switches between the original and the encoding, and "Only what the codec removes" plays the difference. After writing, lossy files are decoded again and their true peak checked; a summary lists every file with its loudness and peaks. Output lists are remembered and can be saved as presets. Save and Save As also write MP3, M4A, Opus and WavPack with their encoder settings; saving a lossy file whose audio you did not change rewrites only its tags, so it is not encoded again.
- Batch Processor (`Ctrl+B`, Tools menu), like WaveLab's: add files, whole folders (with subfolders and a name filter), the files open in your tabs, or drop them on the window. Pick processing steps in order: Normalize Loudness (with a true-peak ceiling), Normalize Peak, Gain, True Peak Limiter, the Master Section as it is now, Trim Silence, Add Silence at Start or End, Fade In and Out, Remove DC Offset, Invert, Mix to Mono, Make Stereo, Change Sample Rate, DeClick, DeClip, DeHum and DeEss. Any step can run only when a condition holds, for example "only if the true peak is above -1 dBTP" or "only if the sample rate is not 44100 Hz". Presets start a streaming master, a podcast or a clean-up. Outputs are the same as Export's (several formats per file, names, folders, tags). Other jobs: Write Tags Only (a tag template with `{variables}`, including `{lufs}`; lossy files are not encoded again), Rename Files from their tags (`{artist} - {title}`), and Measure Only. Every job can write a CSV report with loudness, loudness range, peaks before and after, clipping and what was written. Files run in parallel on every core (or as many at once as you choose) in the background while you keep editing; double-click a result to open it. Batches save as `.phbatch` files, and the last one comes back when you open the window.
- Macros (Tools menu), like Tenacity's: Record Macro (`Ctrl+F9`) records each command you use, with the settings you OK'd in its windows; press `Ctrl+F9` again to name it. Apply Macro (`F9`) runs one on the selection or the file, without its windows appearing. Macros (`Shift+F9`) lists them to run, rename, delete, and add, remove or reorder steps; a step can be set to ask for its settings each time. Each is a `.phmacro` file in `~/.config/phi/macros`.
- Manage Plug-ins (Tools menu): every plug-in with its maker, format and file, a search box, a tick to turn each on or off (turned off ones are not offered when you add a plug-in), the files that crashed or hung while being checked with Try Again, and Rescan. Reset Configuration (Tools menu) puts the window layout, theme, colours and remembered values back to how they were first, optionally the shortcuts and plug-in list too, and restarts; files, macros and the Master Section are kept.
- Metadata (`Ctrl+Alt+M`, File menu), modeled on Audition's Metadata panel: a Common tab (title, artist, album, album artist, track, disc, date, genre, comment, composer, lyricist, conductor, subtitle, grouping, copyright, publisher, ISRC, BPM, key, language, lyrics, URL and more) that every schema follows, and a tab per schema: XMP (all of Adobe's schemas: Dublin Core, Basic, Rights, Media Management, Job Ticket, Dynamic Media, PDF, Photoshop, IPTC Core and Extension, Camera Raw, EXIF, Script; searchable, schemas can be hidden, and Add Property makes custom namespaces), Broadcast Wave (bext v2 with UMID and the loudness fields, Fill In Now), ID3, RIFF INFO, Cart (AES46), iXML, Vorbis comments, MP4 atoms and APEv2. A field left empty follows the Common value (shown greyed); typing gives that schema its own value, listed as a conflict until you Sync. Pictures holds cover art and other pictures. Raw lists every chunk, frame or atom in the file; unknown chunks are kept and written back unless you delete them. Write chooses which schemas are saved for each file type (ID3 version, Strip All). Templates with `{variables}` fill fields in one go; tags import and export as CSV or JSON. Read when a file opens and written when you save (WAV and AIFF by PHI itself, other formats with TagLib, XMP in a `.xmp` file beside formats that cannot hold it). Editing is undoable
- Convert Sample Type (`Ctrl+Alt+T`): change the sample rate (high-quality windowed-sinc filter, flat to 95 % of the new limit and over 90 dB of alias rejection), mix to mono or make stereo, and reduce the bit depth to 24, 16 or 8 bits with TPDF dither or noise-shaped dither, applied now so you hear what will be saved. Markers keep their place in time
- Drawing tools (Phase 2 Part C), in the spectral view: Box (`V`, the usual drag), Lasso (`O`, draw around a sound), Brush (`B`, paint over it) and Spot Healing Brush (`H`, paint over a sound and it is healed when you let go). `[` and `]` change the brush size; hold `Shift` to add to the shape. Auto Heal, Spectral Gain and Delete work on the drawn shape. Add Harmonics (`Ctrl+Alt+H`) extends a selection to its overtones, for a whistle or a hum with partials. Find Similar Sounds (`Ctrl+Shift+F`): select one click, breath or chirp and PHI finds the others like it in the file, then heals them all in one undoable step or marks them as regions to check first
- Diagnostics panel (`Ctrl+Shift+D`, Phase 2 Part D), like Audition's: choose Clicks and crackle, Clipping, Dropouts (lost samples) or Silence, then Scan the selection or the whole file. Move through the list to see and hear each one in the waveform, then Repair the chosen ones, Repair All in one undoable step, Mark them as regions, or (for silence) Delete them
- Restoration (Phase 2 Part B), on the selection or the whole file: Noise Reduction from a learned profile (select noise on its own, `Ctrl+Alt+N`, then `Ctrl+Alt+Shift+N`), DeClick (clicks and vinyl crackle, rebuilt by least-squares interpolation), DeClip (rebuilds cut-off peaks), DeHum (finds 50 or 60 Hz hum and removes it with its overtones) and DeEss. All in the Repair menu and the command palette, with a progress bar and Cancel, and undoable
- Autosave and crash recovery: every minute, each file with unsaved changes is copied (audio, markers and tags) to `~/.cache/phi/recovery`. If PHI closes without you quitting it (a crash, a power cut), the next start offers those copies back: Recover opens each as unsaved, ready to check and save; Discard deletes them. Quitting normally clears the folder. The undo history is not kept. Change the interval with `autosaveSeconds` under `[recovery]` in `~/.config/phi/settings.ini` (0 turns it off).
- Unlimited undo/redo (`Ctrl+Z`, `Ctrl+Shift+Z`) and a History panel (`Ctrl+H`, `Enter` jumps to a step, `Esc` returns to the waveform); you are asked before unsaved changes are lost
- Markers and regions: `M` adds a marker at the cursor, `Shift+M` makes a region from the selection, `'` and `;` jump to the next/previous marker. The Markers panel (`Ctrl+Shift+M`) lists them: `Enter` jumps, `F2` renames, `Del` removes. Markers are saved inside WAV files.
- Panel resizing: drag the line between two panels as usual, or grab the spot where three or four panels meet (the cursor becomes a four-way arrow) to resize both ways at once, as in Adobe Audition.
- Panel focus: the panel that has the keyboard gets the same frame as the waveform (pointing at a panel or Tab gives it the keyboard). `F6` (or `Alt` tapped on its own) moves to the next panel and `Shift+F6` to the previous one, round the waveform, Simplest, Device Chain, Master Section, Meters, Markers, History, Diagnostics, References, Find and the Slicer (a closed panel opens while you are on it and closes again when you move on). Hold `Alt` or `F6` and press an arrow key to go to the panel on that side instead, as between windows in a tiling window manager (closed panels stay closed). `F6` and `Shift+F6` can be changed in Keyboard Shortcuts (`Ctrl+Shift+K`), and holding the new Next Panel key with an arrow works the same way. `Ctrl+W` or `Super+W` closes only what has the keyboard: a panel, the mixer, a window of PHI's own, or the file when the editor has it. `Super+F` takes the window with the keyboard full screen and back. On Hyprland and Omarchy, `Super+W` and `Super+F` reach PHI only if the desktop does not take them itself; `Ctrl+W` always does. `Ctrl+F6` goes straight to the waveform, and each panel's own key (for example `Ctrl+Shift+L` for the meters) still opens and focuses it.
- Waveform and spectrogram blend: `Alt+Shift+Up` moves a tenth towards the spectrogram, `Alt+Shift+Down` towards the waveform, so both show at once (remembered); `Shift+D` still jumps between the two.
- Spectral display (`Shift+D`): spectrogram of every channel, still fully editable, with Sonic Visualiser's controls in Spectrogram Settings (`Alt+Shift+D`, View menu): window size 256 to 32768, window shape (Hann, Hamming, Blackman-Harris), overlap, oversampling, linear, log or mel scale, All Bins, Peak Bins or Peak Frequencies (sharp lines at each peak's exact frequency, by time-frequency reassignment), colour maps, gain, range and normalising per column or over the view. Changes show at once and are remembered. `Alt`+wheel zooms the frequencies around the mouse, `Alt+=` and `Alt+-` zoom in and out, `Alt+0` shows them all (on the waveform the same keys zoom its height, with a dB scale at the left, to see quiet passages and fades); the frequencies are labelled at the left, and the mouse readout shows time, frequency, note and level. Pitch Line (`Shift+P`, View menu) traces the main voice's or instrument's pitch over the spectrogram, and the readout adds the pitch and note under the mouse. Correct Pitch (`Ctrl+Alt+Shift+P`, Repair menu) moves a selected note to the nearest note or one you pick, and can flatten its drift and vibrato, keeping the voice's character (Rubber Band)
- Meters (`Ctrl+Shift+L`): a stereo imaging display on top with six views, one at a time (click it or press `Ctrl+Alt+V` for the next): Goniometer (mid up, side across, with a glowing phosphor-style trace), Polar Sample and Polar Level (half-circle views in the style of iZotope Insight: inside the 45 degree lines is mono-safe), Lissajous (the classic diamond, zooming in by itself on quiet material), with bold L, R, M and S labels, and Binaural (the head from above, showing where each frequency band seems to come from, judged from the time and level differences between the ears; faint, spread dots are room sound), and Mid/Side Levels (mid and side meters in dBFS with peak hold, the side against the mid now and over the last 10 seconds), and a phase correlation meter from -1 to +1, then sample peak bars with peak hold, true peak, and momentary/short-term/integrated loudness (ITU-R BS.1770 / EBU R128) during playback; `Ctrl+Alt+R` resets them. Loudness statistics of the selection or file (`Ctrl+Shift+A`): integrated LUFS, loudness range, true peak.
- Analysis Meters window (`Ctrl+Alt+A`, Analyze and View menus), a mega meter suite in its own window, with Adobe Audition's Analysis detail and the look of a mastering meter: Loudness (BS.1770 / EBU R128) on a gauge around a target you pick (Streaming -14, Apple Music and podcasts -16, Amazon -14 at -2 dBTP, EBU R128 -23, ATSC A/85 -24, CD and club -9), short-term inside, momentary outside, integrated in the middle, with max momentary and short-term, loudness range, true peak and PLR; Loudness History (30 s to 10 min, coloured by how far from the target, with the integrated line); Levels (peak, RMS, peak hold, true peak and clip counts for L and R); Spectrum like Audition's Frequency Analysis (Left & Right, Mid & Side, Average or one channel; lines, filled or bars; 1/24 to 1 octave smoothing; a 3 or 4.5 dB per octave slope; FFT size 1024 to 32768 and window; peak hold; eight hold traces in Audition's colours, `1` to `8`; the frequency, note and level under the mouse; the strongest frequency and its note for each side); a scrolling Spectrogram; Imaging (the Goniometer with all its views); Phase Wheel (each frequency between mono, left, right and inverse, as in Audition); Correlation per third octave with the overall correlation and balance; and Amplitude Statistics as Audition lists them (peak, true peak, sample values, possibly clipped samples, DC offset, total, maximum, minimum and average RMS, dynamic range, crest factor) with an RMS histogram, and Copy; and Ambisonics, where the sound is in an ambisonic file (AmbiX, 1st to 10th order like REAPER's, from the file at the playhead, all its channels), in eight views after the best ambisonic meters and panners: Sphere (a glass globe with a heat map, as 3D Meter has it, that you turn by dragging or with the arrows and bring closer with the wheel or `Ctrl+Up`/`Ctrl+Down`), Four Views (left, front, top and that globe), Panorama (the whole sphere on an equal-area map, as ab Visualiser draws it), Head (the listener from above and from the side with the energy around them, as SoundField shows it), Energy (polar plots from above, behind and the right, front/back/left/right/top/bottom meters and an energy pad with height, after ab Visualiser), Scope (a glowing cloud over a 7.1.4 layout, with a height switch, after PRISM) Speakers (a bar with peak hold for each speaker of a layout you pick, Stereo, Quad, 5.1, 7.1, 7.1.2, 7.1.4, 7.1.8 or 9.1.6, beside the surround energy, after Kaizen; Scope draws the same layout) and Channels (a bar for each ambisonic channel, W, Y, Z, X and on, grouped by order: 4 at 1st order, 121 at 10th). It reads levels against the loudest place or against a full-scale plane wave, and gives the direction and level under the mouse, the loudest direction and how diffuse the sound is; Options pick the range, response and the order shown, and `V` goes to the next view. Files marked Ambisonics in Spatial > Channel Layout, and files of 25 channels and more, count as Ambisonics (4, 9 and 16 unmarked channels too, if you tick that in Options). Everything else measures what you hear, after the Master Section, since the last reset. Hide meters from the Meters button and drag the dividers; both are remembered. Keys: `Space` plays or stops, `R` resets, `F` freezes, `F11` full screen, `Esc`, `Ctrl+W` or `Super+W` closes. Drop audio files on it (from the file manager, or from the Find panel's file list) for a full report of each, measured from the file itself: loudness against the target, amplitude statistics, stereo, an RMS histogram and the average spectrum in third octaves, as text in its own window. Nothing is saved until you say: `Ctrl+S` saves it in the report folder (`~/Documents/PHI Analysis` until you pick another with Folder...), Save As anywhere, and closing an unsaved report (`Ctrl+W`, `Super+W`, `Esc`) asks whether to save it first; Discard lets it go.
- Binaural (`Ctrl+Alt+Shift+B`, Spatial menu, or type "binaural" in Find): places a mono or stereo sound around your head for headphones. Drag the sound around the head seen from above, and up or down in the side view, or use the keys (Left/Right turn it, Up/Down closer or further, Page Up/Down higher or lower, Shift+Left/Right narrower or wider for stereo). Settings: azimuth, elevation, width, distance, room amount and decay, output level, and the HRTF set (the MIT KEMAR set comes built in; put your own `.sofa` files in `~/.local/share/phi/hrtf`). Preview plays the result in a loop and follows your changes. A selection's tail rings on after it; the result is always stereo. 
- Channel layouts (`Ctrl+Alt+Shift+L`, Spatial menu): say what a file's channels are when the count fits more than one layout: 5.1 or Quad-style 4, 6.1 or 5.2 (two subwoofers, LFE1 and LFE2), 7.1.2 or 7.2 for 9 channels, 7.1.4-style 13 as 7.2.4, 16 as 9.1.6, or Ambisonics. Channel names, meters and the stereo fold-down follow it. 9.2.6 (17 channels) and 4th order and higher need more than the 16 channels the engine plays today.
- Ambisonics (Spatial menu, AmbiX: ACN order, SN3D), orders 1 to 3:
  - Encode to Ambisonics (`Ctrl+Alt+Shift+E`): place a mono or stereo sound in the sphere, with the same head view as Binaural.
  - Rotate / Mirror Scene (`Ctrl+Alt+Shift+Y`): yaw, pitch, roll, and swap left/right, front/back or up/down, on the selection or the whole file, with a live preview.
  - Decode Ambisonics (`Ctrl+Alt+Shift+D`): to headphones (binaural, through any HRTF set) or to speakers, from Stereo and Quad through 5.1, 5.2, 7.1, 7.2, 7.1.2, 7.1.4, 7.2.4 to 9.1.6 (AllRAD with max-rE; subwoofer channels are left silent for your bass management).
  - FuMa to AmbiX and AmbiX to FuMa for older B-format files.
  - Speaker Arrays (Spatial menu): your own speaker setup, up to 16 channels in the order of your interface's outputs (name, azimuth, elevation, subwoofer), seen from above and the side, with rings, domes and a cube to start from. Decode Ambisonics and the Ambisonic Studio's master bus list each as Custom: its name and fit an AllRAD decoder (max-rE) to it.
  - Ambisonic Studio (`Ctrl+Alt+Shift+H`): the devices of [Envelop for Live](https://github.com/EnvelopSound/EnvelopForLive) (E4L) in one floating panel that stays open while you work, written for PHI from E4L's documentation (no Max for Live or Ableton needed, and no E4L code). Build a rack on the left, set the chosen device in the middle with its heads-up display (the room from above and from the side; drag a panner's sound), and use the master bus on the right.
    - Sources and voices: Source Panner (mono or stereo, polar or XYZ, radius with E4L's distance model and Range), Mono Panner and Stereo Panner (azimuth, elevation and spread LFOs, free or in time with the tempo), Quad Panner (LR, X and W spread modes), Omni Panner (W only), Multi-Panner (up to 16 channels of the file as a group, with global, scale and per-source offsets), Spinner, Multi-Delay (spiral or pong, synced, azimuth locked to the panner), Brownian Delay (eight wandering voices in a box or wedge, delayed and frequency-shifted), Delay Boids (a flock of delays), AuraVerb (first-order reverb with two-band decay, EQ, compressor and gate) and B-Format Input (an ambisonic file, AmbiX or FuMa).
    - Scene effects: HOA Transform (yaw, pitch, roll, order weights), B-Format Convolution Reverb (a 4-channel B-format impulse response or W/X/Y/Z files, or a built-in hall; size, rotation, early and late, four EQ stages, distance lock), Spatial Slicer (a slice of the sphere cut in and out on tempo triggers) and Gain.
    - Master bus: 1st to 3rd order, the scene's channel meters, an HOA scope, and the decoder: AmbiX, FuMa, headphones (binaural) or any speaker layout. Preview loops the selection (or the first 15 s) and follows every change, heard on headphones, stereo speakers or the decoder's outputs 1+2; Apply renders the whole file with a tail for echoes and reverb (undoable). Racks are kept between sessions, can be saved and loaded as .json, and there are factory presets.
    - Not here yet: E4L's Ableton routing devices (Aux and 3OA Plugin send/return) and the EnvelopLX lighting and OSC devices.
  - Ambisonic Scene (`Ctrl+Alt+Shift+A`): a map of the whole sphere at the playhead (left to right all the way round, up and down), glowing where the sound is.

- Sonify (Visualizer > Sonify, or the Sonify button in the Visualizer window): pictures played as notes, still or moving. The source is whatever the Visualizer shows (any view, MilkDrop too), a picture or a video file or a camera shown in its new Picture view, or the web page behind PHI. The picture is read small (64 by 48, about 20 times a second, off the audio thread): higher up is a higher note, brighter is louder, and change (from one column or frame to the next) strikes General MIDI drums on channel 10, kick at the bottom, snare in the middle, hi-hat at the top. The Φ button (Φ rhythm) lets them play only on the 1s of the Fibonacci word (1011010110110...), a groove that never quite repeats. Scan sweeps a line across, a column per sixteenth note, and plays the bright spots it crosses (for still pictures); Lanes gives each voice a lane that plays where its light is and glides as it moves (for moving ones). Spiral looks at the next point of a sunflower spiral each step, turning by the golden angle (137.5°) from the centre outwards, so a still picture plays as a melody that never repeats. The Pitch slider goes from free (the picture's own pitch, between the notes, by pitch bend) to the notes of the scale (Chromatic, Major, Minor, Pentatonic, Minor Pentatonic, Blues, Dorian, Whole Tone, or Φ: the powers of the golden ratio folded into the octave, between the keys; in any key); each voice has a MIDI channel of its own (1 to 8), as in MPE, so every note bends on its own. Tempo, voices, steps across, the note range and how bright a spot must be are set in the bar. It plays the built-in Synth (put into a free patchbay slot) or whatever the MIDI keyboard plays (Simplest, the Slicer, the Mixer's armed track, or Wavetable, FM and the other synths); set Bend to the instrument's pitch bend range so free pitches land where they should. The scan line and a ring on each sounding spot are drawn over the view.
- Tracker1 (Tracker menu, `Ctrl+Alt+Shift+K`), built on MilkyTracker: opens XM, MOD, IT, S3M and the other module formats MilkyTracker reads, plays them through PHI, and shows the patterns in the classic FastTracker 2 layout (note, instrument, volume, effect) in PHI's theme, following what plays. Each channel has mute (`M`), solo (`S`) and the mixer track it records to (`T`, tracks 1 to 8). `Space` plays the song, `Enter` the pattern, `F` turns following on or off. Record to Editor (`Ctrl+R` stereo, `Ctrl+Shift+R` multi-channel) records the whole song into a new tab: stereo, or a stereo pair per track (up to 16 channels). Editing works like FastTracker 2: `Ctrl+N` starts a new song, `Shift+Space` turns editing on, the keyboard is a piano by key position (`Z` to `M` and `Q` to `P`, `F1` to `F8` pick the octave, `1` or `` ` `` is key off), hex digits fill the instrument, volume and effect columns, `Delete` clears, `Insert`/`Backspace` push and pull rows, `Tab` moves between channels, `Shift`+arrows select, `Ctrl+C`/`X`/`V` copy, cut and paste, `Alt+Up`/`Down` transpose, `Ctrl+Z`/`Ctrl+Y` undo and redo. Notes sound as you type them. `Ctrl+L` loads an audio file into the current instrument, the order list adds, removes and changes patterns, and `Ctrl+S` saves the song as XM. An instrument can play through one of the Retro Sampler's (Ami's) 12 slots instead of its own sample: right-click it, or use the instrument list's Retro Sampler button, and pick a slot. Its notes then go to that slot as MIDI (slot 3 on MIDI channel 3, C-4 as MIDI note 60, the volume as velocity), on the tick they fall on, including note delay and retrigger; key off and note cut let go, and mute and solo apply. The Retro Sampler plays in a patchbay synth slot and is loaded there if it isn't yet, with each of its slots set to listen on its own MIDI channel (so a MIDI keyboard on channel 1 then plays slot 1); linked instruments show `[AMI n]`. Notes typed in sound through it too, and Record to Editor records it (on each track's pair, in multi-channel). Saving the song writes the links and the Retro Sampler's state beside it as `song.xm.ami`, read back when the song opens. Volume and pitch effects don't reach the Retro Sampler yet. Instrument envelopes and a sample editor come next.
- Tracker2 (Tracker menu): Furnace, the chiptune tracker for over 80 sound chips (Genesis, NES, Game Boy, C64, Amiga, arcade FM and many more), in its own window with its own look, built by PHI from its source. A thin opacity bar runs along the bottom of its window, as on the instruments' windows: drag or scroll it, double-click for solid; Furnace keeps it in its own settings. It is its own program and plays through the desktop's sound (PipeWire, JACK or ALSA), so it stays open when PHI closes and isn't recorded by Record to Editor (record it with Performance as an application, or export from Furnace).
- Performance menu: video recording and live streaming of PHI, like OBS but for PHI alone. Record Video (`Ctrl+F12`, again to stop) writes an MP4 with H.265 (HEVC) video and AAC sound to `~/Videos/PHI`; Go Live (`Shift+F12`) streams to YouTube, Twitch, Facebook Live or any RTMP, RTMPS or SRT server; both run at once from one picture. Only PHI is ever in the picture: it draws its own window into the video (so no other window or screen can get in, and Wayland asks nothing), following the PHI window in front if you like, and always the full-screen Visualizer (`F11`). The window is drawn at the video's size, so text stays sharp at 4K. Resolution is 1080p, 1440p or 4K, chosen automatically from the computer: 4K with a graphics card that encodes H.265 (VAAPI on AMD and Intel, NVENC on NVIDIA), else x265 on the processor at 1080p (1440p with 16 cores or more); 24 to 60 frames a second. Webcams and capture cards go on top in a corner, and can each also be kept whole on a video track of their own for multicam editing. The sound is what PHI plays (after the Master Section, the Tracker, the Mixer and the instruments) plus any microphones and applications such as a web browser (found by name and heard whenever they play), in several AAC tracks: the stereo mix first (what players and the stream use), then PHI alone in all its channels (5.1, 7.1, Ambisonics), then each microphone or application alone. Video and Stream Settings sets all of this. The status bar shows REC and LIVE with their time. Performance > Clip Launcher (`F5`) opens the mixer with a grid of clips in its upper area, Ableton style (docs/clip-launcher.md): tracks across, scenes down with a launch button each, a stop button under each track, the selected track's rack (instrument, track settings, clip) on the left and compact strips (name, pan, mute, solo, fader, meter) below. With it showing, Enter or a double-click on a sound in the Find panel puts it into the first empty slot of the track named for its Selector colour (DR, BA, PR... in Live Performance), and the mixer follows to that track; one pick per colour builds a scene. Clips launch on the launch quantise (off, 1/16 to 8 bars, 1 bar to start), loop or play once, one per track; launching takes a track off its timeline until Back to Timeline (`T`). The slots are saved in the project.
- Sample menu: Simplest, the first of the Sample menu's samplers (more are to come, and they and any synths will open as floating windows). `F7` sends the selection (or the whole file) to Simplest and plays it across the keyboard; with Follow editor on, every later edit to that sound in the editor reaches the Sampler at once, keeping its start, end and loop (`Ctrl+F7` refreshes by hand, `Shift+F7` shows the window). With no file open, `F7` opens Simplest empty, ready for a sound dropped on it, and `F8` does the same for the Slicer. In Find, `F7` and `F8` send the highlighted file to Simplest or the Slicer and leave the keyboard in Find, so you can arrow to the next file and try it. Classic mode loops the shaded part while a key is held and shapes it with Attack, Decay, Sustain and Release; 1-Shot plays the whole sound with short fades whatever the key does. Drag the white S and E lines to set where it starts and ends and the L lines for the loop (they snap to zero crossings), and set gain, pan, transpose, detune, root key, voices (1 to 32) and how much velocity matters. Play it from the computer keyboard (`A` to `K` and `W` `E` `T` `Y` `U` as in Live, `Z`/`X` octave, `C`/`V` velocity, `Esc` back to playing from a field) or any MIDI keyboard or pad controller (Sample > MIDI Inputs; sustain pedal and pitch bend work, `Shift+Esc` is all notes off). It sounds on top of whatever plays, file or Tracker. The Analyze menu's key is now `Alt+N` (`Alt+A` opens Sample).
- Sample menu: the Slicer, after Ninjas2. `F8` cuts the selection (or the whole file) into slices on 64 pads, four banks of 16 (A to D), laid out for Push's 8x8 grid in User mode: bank A bottom left, B bottom right, C top left, D top right (or Chromatic, 16 notes a bank from C1 as in Live's drum racks). Slice by transients (with a sensitivity), equal parts (2 to 64), the file's beat grid (bars, beats, 8ths or 16ths) or the editor's markers; drag a slice line to move it, double-click to add one, right-click a line to remove it. Each pad has its own gain, pan, pitch, reverse, One shot or Gate play, attack, release and choke group (open and closed hats); the kit has velocity and voices. Play it by clicking slices or pads (higher on a pad is louder), from Push or any MIDI pads, or from the computer keyboard: `Z X C V`, `A S D F`, `Q W E R`, `1 2 3 4` are the bank's pads from the bottom row up, `5 6 7 8` choose banks A to D. A pad hit from MIDI becomes the one you edit. Follow editor, `Ctrl+F8` (refresh) and `Shift+F8` (window) work as for the Sampler. MIDI notes play whichever of the two windows you used last. Simplest and the Slicer open in their own windows, so they get the room they need whatever panels are open (on Hyprland they tile, and `Super+F` takes one full screen). `Ctrl+Alt+P` docks one instead, and it then stays docked until popped out again: Simplest along the bottom beside the Device Chain, the Slicer on the left under Find (in its place when Find is closed), each scrolling rather than pushing into the panels around it; drag an audio file from the Find panel or a file manager onto either to load it, drag a title bar to move one anywhere, or pop it out into its own window with `Ctrl+Alt+P`. Closing one silences it, and with both closed MIDI plays nothing.
- Instruments: free samplers and synths built with PHI from their own source, named by what they do. The Sample menu has the samplers, Granular (GRNLR) and Retro Sampler (Ami); the Synth menu has the synths, Wavetable (Vaporizer2), Modular (Cardinal, with only its host modules and VCV Fundamental's oscillators, filter, amplifiers, envelope, LFOs, noise, mixers, sequencer and scope), Additive (Overtonium), Subtractive1 mono (CA-72, a Minimoog Model D), Subtractive2 poly (Helm) and FM (OctaSine). Find lists them under Instruments. Each opens in its own floating window with its own look and fonts, untouched, and a thin opacity bar along the bottom (drag or scroll it, double-click for solid; each instrument remembers its own). It plays as one of the patchbay's four synths, so the MIDI keyboard plays it, the Patchbay (`F4`) routes it, and the mixer's tracks can use it too. OctaSine draws with OpenGL 3.2 and 4x multisampling, which any graphics driver has but some virtual machines lack.
- Mixer menu: the 8-track mixer (`F3`), which takes the editor's place between the side panels; `F3` again or `Ctrl+W` closes it, and the next `F3` brings it back as you left it. `Ctrl+Shift+F3` (or `Ctrl+Alt+P` from the mixer) undocks it into a window of its own and docks it back, and `Super+F` takes it full screen. Every track is the same kind of track, as in Reaper, Bitwig or Tracktion: a timeline of clips, each an audio file or a MIDI file (standard MIDI file types 0 and 1, played as it is, never edited), one after another or overlapping, plus an instrument that the MIDI clips play. The instrument is the built-in Synth (sine, triangle, saw or square through a low-pass, with General MIDI drums on channel 10, so any MIDI file sounds at once), a Sampler or Slicer of the track's own (its sound from a file or from the Sample menu; Edit opens the usual Sampler or Slicer window for it), or any VST3, LV2 or CLAP instrument plugin found by the plugin scan (Edit opens its own window). The armed track (`R`, the dot) is also played by the MIDI keyboard. The window has three sections, and `F6` or `Tab` goes round them (`Shift` backwards). On the left is a file browser (`Ctrl+B` shows or hides it): arrows walk folders and files, `Enter` or a double-click puts the file on the selected track at the playhead and moves the playhead to its end, so files can be laid one after another (`Shift+Enter` leaves the playhead), `Backspace` goes up a folder, and the ★ keeps a folder among the favourites. In the middle the tracks run across time, one row each (`V` shows or hides them): audio clips show their waveform and MIDI clips their notes, and overlapping clips stack within the row. Drag files from the browser or the file manager onto any spot of a row (several land one after another). Drag clips with the mouse to move them in time or to another track (`Ctrl` copies, `Shift` leaves the grid, `G` turns the grid off and on), drag a clip's edge to trim it, click or drag on empty space to move the playhead, `Ctrl`+wheel to zoom and double-click the ruler to see the whole mix. With the rows focused, `Left`/`Right` move the playhead a beat (`Ctrl` a bar), `Up`/`Down` pick the track, `Delete` removes the selected clips, `Ctrl+E` splits at the playhead, `Ctrl+D` duplicates, `Shift+M` mutes and `R` reverses them (an audio clip plays backwards, a MIDI clip plays its notes in reverse, and `R` again turns it back); right-click for the same. Double-click an audio clip to edit it in the editor: the mixer steps aside but keeps running, the clip opens in a tab of its own, and `F3` puts the edit back on the track (saved as a WAV in an `Edits` folder beside the mix, or in `~/Music/PHI Edits` before the mix is saved), closes that tab and brings the mixer back; `Ctrl+Z` in the mixer undoes it. `Ctrl+Z` and `Ctrl+Shift+Z` undo and redo clip edits. Below are the strips: the instrument, transpose (the drums stay put) and which MIDI channels play, trim (±24 dB), polarity per side, pan (equal power for mono files, balance otherwise), mute and solo, and a fader (−∞ to +6 dB, marked in dB of boost and cut on its left; drag it, `Shift` for fine moves, double-click for 0 dB) with a peak and RMS meter marked in dBFS on its right, peak hold and clip light. The trim and pan dials are the same knobs as the rest of PHI. A new mix starts with 2 tracks; `Ctrl+T` adds one up to 8 and `Ctrl+Shift+T` removes the last. The master has a fader and meter and no plugins: mastering stays the editor's job. `Space` plays and stops (`Shift+F3` from anywhere), `Home` goes to the start, `L` loops the whole mix, `1` to `8` pick a track and `9` the master, and with the strips focused `Left`/`Right` move between them, `Up`/`Down` move the fader (`Shift` for 0.1 dB), `[`/`]` pan, `0` resets the fader, `M` mute, `S` solo, `E` edits the instrument, `A` and `I` add an audio or MIDI file at the playhead. The tempo box sets bars and beats; MIDI follows tempo plays the MIDI files at it instead of their own tempo maps. Projects save as `.phi` files (`Ctrl+S`, `Ctrl+O`, Mixer > Save Project; [docs/project.md](docs/project.md)) with every clip, setting and instrument (plugin settings included; sounds taken from the Sample menu are saved as WAVs beside the project), the patchbay's patches, synths and effects, and whether the Mixer was in front. The project you had open comes back when PHI starts again, unsaved changes and all, with the Mixer in front if you left it there. A `.phi` also opens with File > Open, from the command line or from the file manager; `.phinyxmix` mixes from before still open, and mixes from before clips open with one clip per file. Mix Down to Editor (`Ctrl+F3`, or `Ctrl+Enter` in the mixer) renders the whole mix with the instruments' tails into a new stereo tab. Bounce renders one track by itself (its MIDI clips through its instrument, plus its audio clips, before the fader and pan) to a 32-bit WAV in a `Bounces` folder beside the mix: Bounce in Place (`B`, or right-click the strip) puts it on the track and mutes the clips it came from (they stay, so you can go back), and Bounce to New Track (`Shift+B`) puts it on a new track with the same fader and pan and mutes the original, which needs a free track, so not when all 8 are in use. The mixer is heard on top of the editor, like the Sampler.
- Mixer > Patchbay (`F4`): an 8x8 patchbay in its own window, one routing graph for everything played live (see [docs/patchbay.md](docs/patchbay.md)). Sources down the side (the editor's playback, the Sampler, the Slicer, 4 synths of its own with the built-in Synth or any instrument plugin, the mixer's 8 tracks, the Mix Bus and 4 FX buses with an effect plugin each) against destinations across the top (the tracks' inputs, the Mix Bus, the FX buses and the Main Out). It fills itself with what is in use. Click a jack to patch, drag or scroll it for its gain; patches that would feed back are crossed out and refused. Every source starts where it was heard before, so nothing changes until you patch. Patches, synths and effects come back next time.
- Warp menu: a beat grid and stretching to a tempo. Detect Beat Grid finds the beats and bars (QM bar and beat tracker), fits a steady tempo and moves the grid onto the hits, with bar 1 on the beat with the most low-end punch; bar, beat and sixteenth lines show over the waveform with bar numbers (`Ctrl+J` shows or hides them). Set Tempo and Grid (`Ctrl+Shift+J`), Bar 1 Starts at the Cursor (`Ctrl+Alt+J`), Halve and Double Tempo. Stretch to Tempo (`Ctrl+Alt+Shift+J`) changes the selection or the whole file to a new BPM, or fits it to exactly N bars, with Rubber Band (Full Mix, Full Mix + Voice, Drums, Melody) keeping the pitch, or Varispeed changing speed and pitch together like tape; every channel is stretched together. The tempo is saved as the file's BPM tag. Edit Warp Markers (`Shift+W`) finds the hits (transients) and shows them as grey ticks along the top of the waveform: drag a tick to move that hit (it snaps to sixteenths; hold Alt to move freely) and only the audio between its neighbours stretches, so the flag (warp marker) stays put and undo puts it back. `W` adds or removes a marker at the cursor, `,` and `.` jump to the previous or next hit, `Ctrl+Alt+Left/Right` nudge the marker at the cursor by a sixteenth (add Shift for 1 ms). Quantize (`Q`) moves the hits in the selection or the whole file onto the grid with the Quantize panel's settings. The Quantize panel (`Shift+Q`, docks or pops out into its own window; see [docs/quantize.md](docs/quantize.md)) brings Cubase's Hitpoints and Quantize Panel and Live's warping together: hitpoints found by level, spectrum (notes that change without getting louder) or both, with threshold, minimum gap and a keep-only-1/4, 1/8 or 1/16 filter; Create Warp Markers, Create Slices and Create Groove from the hits; grid 1/1 to 1/64, straight, triplet or dotted; strength, swing, catch range, non-quantize zone, randomize, iterative quantize and Auto Apply; groove templates (MPC-style swing, shuffle, pushed and laid-back feels, and grooves taken from your own audio); a one-bar picture of the grid with the hits folded onto it; and nine warp algorithms (Full Mix, Full Mix + Voice, Drums, Beats, Beats No Loop, Melody, Texture, Smooth, Varispeed). Ctrl+Alt+drag the end of a selection to stretch or shrink it to where you let go. The time ruler counts time, bars and beats (1, 1.2, 1.2.3), or both on two rows (Warp or View menu: Ruler in Time, in Bars and Beats, in Time and Beats). The BPM box beside the time shows the tempo; type a new one and press Enter. Files up to a minute long with no tempo get one as they open, as in Acid and Live (Warp > Detect Tempo When Opening Loops); short, busy jungle and drum and bass breaks are read from the loop's length and hits, since a loop is a whole number of bars. Editing like Live's arrangement: Snap to Grid (`Ctrl+4`, on by default once a file has a tempo) makes clicks and selections land on the finest grid line the zoom shows, `Ctrl+1`/`Ctrl+2` narrow or widen it; drag a selection to move it (it overwrites where it lands and leaves silence behind; hold Ctrl or Alt to copy instead); `Ctrl+D` duplicates the selection right after itself, over what is there; `Ctrl+E` splits (a slice marker at the cursor or at both ends of the selection); double-click between markers, or between hits while editing warp markers, selects that slice; `R` reverses the selection; `Z` zooms to the selection (it was `Ctrl+E`). `*` stretches the selection or the whole file to twice as long and `/` shrinks it to half as long, pitch kept; pressing them again goes on (4×, 8×...) as one clean stretch from the original. Halve and Double Grid Tempo only change how the beats are counted. Export Loop (`Ctrl+Alt+L`) saves whole bars as a WAV loop: pick the start bar and how many bars, and the seam is crossfaded so it loops without a click; the file carries its tempo, length in beats and loop points, so samplers and DAWs (Acid, Live, FL Studio, hardware samplers) loop it in time.
- Audio Interface Mixer (`Ctrl+Alt+Shift+I`, Options menu): opens your interface's routing and mixer program, alsa-scarlett-gui by default (Focusrite Scarlett and Clarett), or brings it to the front on Hyprland. If it is missing it tells you how to install it (`yay -S alsa-scarlett-gui`); choose another program with Options > Audio Interface Mixer Program.
- Panels (Master Section, Meters, Markers, History) dock in the window or pop out into their own window with `Ctrl+Alt+P`, so Hyprland tiles them like any other window; all shortcuts work there too, and `Esc` closes the window and returns to the waveform (unless you are typing in a field). The layout is remembered.
- Gain knob and fade handles, like Audition's: a small bare knob floats over the waveform; turn it off or on with View > Gain Knob (`Ctrl+Alt+K`). Drag it (up or right is louder, Shift is finer) or turn the mouse wheel over it and the selection, or the whole file, changes level while you watch and listen; the status bar shows the dB while you adjust, letting go makes it one undo step and the knob goes back to 0 dB (double-click it to type a value). Drag it with the right mouse button (or `Ctrl` and the left) to put it anywhere over the waveform; it stays there. From the keyboard, `Ctrl+Shift+Up` and `Ctrl+Shift+Down` do the same in 0.5 dB steps, applied when you stop pressing. The square handles at the top corners of the waveform are fades: drag one inwards for the fade's length, and up or down to bend it (up rises fast and levels off, down starts slow), shown as a curve while you drag. The keyboard fades (`Ctrl+Shift+I`, `Ctrl+Shift+O`) work on the selection as before.
- Master Section (`Ctrl+Shift+E`), like WaveLab's: 8 plugin slots plus master gain, applied to everything you play. Hosts VST3, CLAP, LV2 and LADSPA effects (scan with `Ctrl+Alt+Shift+S`, add with `Ctrl+Alt+E`). Each plugin file is checked by a separate helper copy of PHI, so a plugin that crashes or hangs while being scanned is just skipped from then on and never takes the editor down. Windows plugins work through [yabridge](https://github.com/robbert-vdh/yabridge): after `yabridgectl sync`, its VST3 and CLAP copies in `~/.vst3/yabridge` and `~/.clap/yabridge` are found by the next scan (VST2 is not supported). If a plugin stops working while you use it (a Windows plugin whose Wine side closes makes yabridge report "write: Broken pipe"), PHI switches just that plugin off, lets the sound pass through, marks its card in red and keeps running; press Reload on the card (or `E`) to load it again with its last settings. In the slot list `Enter` opens a keyboard-friendly parameter editor (type to filter, arrows to adjust), `E` opens the plugin's own window (needs XWayland) and closes it again, `B` bypasses, `Del` removes, `Ctrl+Up`/`Down` reorders. `Ctrl+Shift+B` bypasses the whole section. Render in Place (`Ctrl+Shift+Enter`, a bounce) applies it to the selection, or the whole file, as an undoable edit and then bypasses the section so the effect is not heard twice. Render to New Tab (`Ctrl+Alt+Shift+Enter`) puts the rendered selection or file into a new untitled tab with its markers and tags, leaving this file and the Master Section as they are. To write files through it, use Export (`Ctrl+Alt+X`) with Through the Master Section. Plugin latency is compensated. While you listen, the cursor follows what you hear (behind by the plugins' and the sound card's delay), and switching a plugin off, soloing one or bypassing the section keeps the sound in time. The chain is remembered between sessions.
- A/B Reference section, like WaveLab's reference tracks (References panel, `Ctrl+Alt+Shift+R`, also in the Master menu): add finished songs or earlier versions to compare with yours (`Insert` in the panel). `A` switches between your audio and the chosen reference at the same moment in the song, with a short crossfade so it never clicks; `Shift+A` goes to the next reference. References are matched in loudness to your audio as it sounds through the Master Section (measured on the first switch, again with Match Loudness), and a Level offset per reference (`+`/`-` in the list) adjusts that. By default references are heard without the Master Section, kept in time with it; untick the box to hear them through it. While a reference plays, "B" and its name show at the top right of the waveform, and the meters measure what you hear. The list is remembered.
- Master Assistant (`Alt+Shift+M`, Master menu), like the mastering assistants of Ozone, but it only turns the knobs of the chain you built (or loaded from a preset) and never adds, removes or moves a plugin. Aim for a reference from the References panel (its loudness, peak-to-loudness ratio, tonal balance in octaves and stereo width, as Matchering compares them) or a preset (Streaming -14 LUFS, Apple Music and podcasts -16, Amazon -14 at -2 dBTP, Loud -9, EBU R128 -23) with a tone of your own, Balanced, Warm or Bright, and a true peak ceiling. Tick Loudness, Tone, Dynamics and Width to say what to match, and choose how far a knob may move from where you left it. The list shows every parameter of every plugin in the Master Section (inside Prisms too), any plugin: gains, EQ band gains, thresholds, ratios and widths are ticked to start with; frequencies, times, ceilings, modes and switches are not, and a knob only moves for its own job (an EQ band when the tone is matched, a width when the width is, so nothing is widened just to get louder). Suggest renders about 30 seconds of the loudest parts and one typical part through the chain for every try, measures it and turns the ticked knobs a step closer each time (a Levenberg-Marquardt fit), usually in 10 to 60 seconds; playback stops meanwhile. Then it shows each knob's old and new value and the measures before, after and in the target, all for the whole song. You hear the suggestion at once: Amount blends between your settings and its settings, `A` switches between them, `Space` plays, Keep keeps what you hear, and Revert or `Esc` puts every knob back.
- Album, for putting an album together (Album menu, `Alt+B`; new one with `Ctrl+Alt+Shift+M`), in the spirit of WaveLab's Audio Montage: add songs with `Alt+Insert` (or open them from the Find panel while the album is in front), `Alt+Left`/`Alt+Right` move between songs, `Alt+Shift+Left`/`Right` change their order, `Alt+Up`/`Alt+Down` lengthen or shorten the pause before a song in half seconds (below zero the songs crossfade, equal power), `Alt+Enter` sets a song's title, artist, ISRC, gain, fades and the part of the file used, `Alt+Shift+Enter` the album's title, artist and UPC/EAN, `Alt+Shift+T` switches between one track (overlapping songs crossfade by themselves) and two tracks like WaveLab's (songs alternate between them and overlap freely, each shaped by its own fade in and fade out from Song Properties), `Alt+Delete` removes a song. The album plays through the Master Section with the meters like any file; its songs show as blocks above the waveform and as track regions. `Ctrl+Alt+Enter` opens a song in its own tab to edit it, and the album picks up the edits when you go back to it, saved or not. Songs at another sample rate are converted. Save keeps a small `.phalbum` file that points to the songs (older `.album` files still open). Export Album (`Ctrl+Alt+Shift+X`) writes the whole album as one file with a CUE sheet (track and pregap indexes, ISRC, CD-Text titles, catalogue number) and/or a gapless file per song with its tags, through the Master Section if you like.
- Analysis with Vamp plugins, as in Sonic Visualiser (Analyze menu, on the selection or the whole file): Mark Beats (`Ctrl+Alt+B`) puts a marker on every beat, named by bar and beat ("Bar 3", "Beat 3.2"); Mark Onsets (`Ctrl+Alt+Shift+O`) marks every hit or note start; Detect Tempo and Key (`Ctrl+Alt+Shift+T`) finds the BPM and key and writes them to the tags (FLAC BPM and INITIALKEY, the WAV acid tempo; in an album, to the song under the cursor). Vamp Plugins (`Ctrl+Alt+Shift+V`) lists every Vamp plugin found (type to search) and runs one: its results become markers, or regions when they have a length; the Find panel lists them too. Markers > Export Slices at Markers writes each piece between markers to its own numbered file, for samplers; Export Markers as Labels writes them as Audacity or Sonic Visualiser labels or CSV. The QM Vamp Plugins (beat, bar, tempo, onset, key, and more) come with PHI on x86-64; other Vamp plugins are found in `~/vamp`, `~/.vamp`, `/usr/local/lib/vamp`, `/usr/lib/vamp` or `VAMP_PATH`.
- Generate (Effect > Generate): Tone (`Ctrl+Shift+G`) makes a sine, square (with pulse width), sawtooth or triangle wave at any frequency, or a sweep from one frequency to another, band-limited so it does not alias (switch that off to hear the raw shape alias, for teaching); Noise (`Ctrl+Alt+Shift+G`) makes white, pink, brown, blue or violet noise, different in each channel or the same. Both replace the selection, insert at the cursor, or make a new file when nothing is open
- Nyquist effects, as in Audacity (Nyquist by Roger B. Dannenberg; libnyquist from Audacity 3.7.9). **Effect** menu (`Alt+C`): Audacity's Adjustable Fade, Delay, Legacy Limiter, Noise Gate, Notch Filter, Spectral Delete and Spectral Edit Shelves (they use the frequency band you select in the spectral display), Studio Fade Out and Tremolo, with a Generate submenu (Pluck, Rhythm Track, Risset Drum); Repeat Last Effect is `Ctrl+Shift+Y`. **Analyze** gains Label Sounds and Measure RMS; labels they make become markers. **Tools** menu (`Alt+L`): Nyquist Prompt (`Ctrl+Alt+Y`; type Lisp or SAL, `Ctrl+Enter` runs it on the selection or the whole file, Debug shows what it printed), Nyquist Plugin Installer, Regular Interval Labels, Sample Data Export and Import, Open Nyquist Plug-ins Folder and Rescan. Your own `.ny` files go in `~/.local/share/phi/plug-ins`; an installed Audacity's plug-ins (`/usr/share/audacity/plug-ins` and its user folders) are listed too. Each effect opens a dialog built from its controls, which remembers your values. Every one is a command, so it is in the palette and can get a shortcut. Not yet: Preview, and Audacity's scripting (`AUD-DO`).
- Mastering effects, under Built-in in Add plugin: True Peak Limiter (Input, Ceiling in dBTP, Release; a look-ahead limiter that keeps peaks between samples under the ceiling too) Stereoize and Mid/Side Width.
- Φ effects, PHI's own effects built on the golden ratio φ (1.618...) and the Fibonacci numbers, under Built-in in Add plugin (they exist only in PHI): Φ EQ (a Super Low shelf at 80 Hz, ten bells at 80 Hz × φⁿ from 129 Hz to 9.8 kHz, each one golden step wide, and a Super High shelf at 15.9 kHz), Φ Echo (taps at time × φ⁰, φ¹, φ²..., each 1/φ quieter by default, panned around the stereo field by the golden angle; Time, Decay, Feedback, Mix, Taps, Spread), Φ Space (a reverb of eight delay lines √φ apart in length, so they never ring together; Size, Decay, Damping, Mix, Pre-delay), Φ Drift (chorus, tremolo or auto-pan moved by three LFOs at rate × 1, φ and φ², a motion that never repeats) and Φ Rhythm (a gate playing the Fibonacci word, a rhythm that never repeats yet never clumps, at 61.8, 38.2, 23.6 or 14.6 % of the steps; Tempo, Density, Shift, Depth, Step, Smooth). Also: Φ Resonator (very narrow band-passes at a root × φⁿ, e.g. 220, 356, 576, 932, 1507 Hz, the root centred and the rest fanned left, right, left; Noise mixes in white noise to play it as a sound source), Φ Stack (copies pitched up by φ, φ², φ³, φ⁴, each 8.33 semitones above the last, fanned around the original, with a Tone low-pass), Φ Tame (the "golden EQ": a cut at the fundamental × φ ÷ 2 × 10, which it finds by itself between 25 and 250 Hz, e.g. 58.9 Hz → 476.5 Hz, softening drums and loops like gentle compression without touching their dynamics) and Φ De-resonator (turns resonances down while they ring, each frequency compared with its neighbours over one golden step; Depth, Sharpness, Speed, Mix, Low, High, Delta to hear what it removes; cuts recover φ times slower than they close; 2048 samples of latency at 48 kHz). Defaults lean on golden numbers too (61.8 %, 38.2 %, 13 ms, 233 ms).
- Final dither, built into the Master Section after the master gain so it never takes a plugin slot: Off, 16, 20 or 24 bits, with plain rounding, TPDF or shaped noise (Dither and Noise knobs on the Master card, or the Final dither row in the Master Section panel). It applies to playback and Render in Place; exports and batch outputs round to their own bit depth as their last step instead. A chain saved with the old Dither effect in a slot moves its settings here.
- Stock plugins (Phase 3), listed under Built-in in Add plugin: ToneShiftEQ (12-band EQ with dynamic bands), Wolf Shaper (waveshaper with a drawable curve), LSP Clipper and LSP Multiband Clipper (mono and stereo), LSP Oscilloscope (x1, x2 and x4), and ZL Audio's ZL Equalizer 2 (dynamic EQ with minimum, matched, mixed and zero phase), ZL Spectrum Equalizer, ZL Compressor, ZL Limiter (true peak, up to 32x oversampling) and ZL Splitter (mid/side, low/high, transient/steady). They are built with PHI and open in one PHI frame: a header with the plugin's name and credit, A/B compare (B starts as a copy of A; Copy puts what you hear onto the other side) and On/Off; input and output meters at the sides; the plugin's own view in the middle; and a footer of knobs for its main controls, which are also the knobs on its Device Chain card. The frame takes its colours from your theme.
- Device chain (`Ctrl+Shift+C`), like Ableton and Bitwig: the Master Section's plugins as cards along the bottom of the window, left to right into the master gain. Each card has on/off, solo (hear only that plugin while playing), its first knobs, a level bar, Edit and Window buttons. Keys: `Left`/`Right` pick a card, `Up`/`Down` pick a knob, `+`/`-` turn it (`Shift` or `Page Up`/`Down` for bigger steps), `F2` or just typing a number sets an exact value (so does double-clicking a knob; `Enter` sets it, `Esc` cancels), `Enter` edits all parameters, `Insert` adds a plugin after the card, `Del` removes it, `B` bypasses, `S` solos, `E` opens the plugin's window, `Ctrl+Left`/`Right` moves it, `Esc` goes back to the waveform. Drag a card by its name to move it with the mouse. Knobs are drawn like Ableton Live's, with the value filled in along an arc (the master gain fills from 0 dB); drag up or down to turn one, with `Shift` for fine steps.
- Prisms ([docs/prism.md](docs/prism.md)): a device in the Device Chain that splits the sound into rays of plugins (Parallel, Bands with up to four Linkwitz-Riley bands, Mid/Side or Left/Right), keeps the rays in time and joins them again; rays hold Prisms too. Add one from Add plugin (Prism under Built-in), or pick cards with `Shift+Left/Right` and group them with `Ctrl+G` (`Ctrl+Shift+G` ungroups). Docked it is one card with eight macro potentiometers; `Enter` pops it out over the window to edit its rays, and `Esc` docks it back. Map puts any knob in its rays on a macro with a range of its own, and right-click a macro to learn a MIDI controller.
- Focus follows the mouse (View > Focus Follows Mouse, on by default), like Hyprland: point at the waveform, the device chain or a panel and your keys go there, no click needed. It never pulls focus out of a text field or dialog.
- CPU meter at the bottom right (View > CPU Meter turns it off): `CPU` is what PHI uses of the processor, all its threads together, updated every second (100% is one core, as `top` and Hyprland's own CPU widget count it); `Audio` is how much of each audio block's time the sound takes to make, turning red from 80% (near 100% it drops out). A Release build uses noticeably less than a debug build.
- Window opacity: slider at the bottom right or View > Window Opacity; `Ctrl+Alt+-` and `Ctrl+Alt+=` change it. Your compositor's own opacity (for example a Hyprland window rule) still applies on top.
- Waveform and meter colours (`Ctrl+Shift+W`, Options > Waveform and Meter Colors): pick your own waveform, background, selection, cursor, centre line, marker and region colours, the imaging display's trace, and the meter colours (low, middle, high, peak hold); they apply on top of any theme and "Theme default" puts one back. The colour picker is part of the same window, and changes show at once. Colour Waveform by Level (`Ctrl+Alt+Shift+W`, View menu) colours the waveform by how loud it is, blending from blue when quiet through cyan, green, yellow and orange to red at 0 dBFS; the six level colours are in the same dialog and in themes
- Themes (`Ctrl+Shift+T`): PHI Dark and Light built in, plus your own JSON themes in `~/.local/share/phi/themes` (see [docs/themes.md](docs/themes.md))
- Every action is a command with a keybinding:
  - `Ctrl+Shift+P` or `F1`: command palette, searches every command and shows its shortcut
  - `F10` or `Alt+F/E/P/R/C/M/B/A/L/S/T/V/O/H`: open menus, then arrow keys
  - `Ctrl+Shift+K`: change any key binding, with conflict detection; saved to `~/.config/phi/keymap.ini`
  - On Hyprland (Omarchy), PHI reads the desktop's own key bindings (`hyprctl binds`) and warns when one of its shortcuts is already taken, since those keys never reach the app. PHI never uses the Super key, which Omarchy keeps for itself.
  - `Ctrl+,`: choose the audio output device

## Build and run (Arch Linux)
```sh
sudo pacman -S --needed base-devel git cmake ninja qt6-base qt6-wayland alsa-lib libpipewire ladspa clap \
  freetype2 fontconfig libx11 libxrandr libxinerama libxcursor libxcomposite libxext libxi mesa cairo libsndfile clang \
  ffmpeg taglib python rust xcb-util-wm fftw curl wget
git clone https://github.com/phinyx852Hz/audio-editor
cd audio-editor
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/phi_artefacts/Release/phi
```
Run the core tests with `ctest --test-dir build`.
Do not install `jack2` on Omarchy or any PipeWire system: it conflicts with `pipewire-jack`, which PHI uses for JACK output. Keep `pipewire-jack`.

JUCE 8.0.15 is downloaded automatically during the first configure (the freetype/X11 packages above are only needed to build JUCE's small `juceaide` helper); pass `-DJUCE_DIR=/path/to/JUCE` to use a local checkout.

The `clap` package provides the CLAP plugin headers; without it they are downloaded during configure (or pass `-DCLAP_DIR=/path/to/clap`).

The stock plugins are downloaded and built from their own repositories (pinned versions) during the first build, which needs `cairo`, `libsndfile`, `libxi` and Clang 17 or later (`clang`; without it the ZL plugins are left out). The ZL plugins make that first build much longer, up to an hour or two on an older laptop; later builds are quick. They build after PHI itself, one at a time, with one job per 3 GB of memory (set `-DPHI_STOCK_JOBS=N` to change that). Add `-DPHI_STOCK_PLUGINS=OFF` to build without them. The instruments build with them; CA-72 and OctaSine need Rust (`rust` or `rustup`) and are left out without it, and `-DPHI_STOCK_INSTRUMENTS=OFF` leaves all the instruments out.

For Visualizer > Web Page, install `qt6-webengine` (`qt6-webengine-dev` on Ubuntu) before configuring; `-DPHI_WEB_BACKDROP=OFF` leaves it out even when it is installed.

For Performance > Record Video at 4K, the graphics card does the encoding: on AMD and Intel that needs the VAAPI driver (Mesa's, in `mesa` or `libva-mesa-driver`, for AMD; `sudo pacman -S intel-media-driver` for Intel; `vainfo` from `libva-utils` should list `VAProfileHEVCMain` with `VAEntrypointEncSlice`), on NVIDIA the proprietary driver (`nvidia-utils`). Without one, x265 encodes on the processor at 1080p.

For more plugins, `sudo pacman -S lsp-plugins` gives a large free mastering set (EQ, compressors, limiters). `sudo pacman -S dragonfly-reverb-clap` adds free CLAP reverbs; `sudo pacman -S clap-plugins` installs every CLAP plugin Arch packages.

To install system wide instead, use the PKGBUILD: `cd packaging/arch && makepkg -si`.

## Hyprland
PHI runs natively on Wayland. Its window class is `phi`, so you can target it in `hyprland.conf`, e.g.
`windowrulev2 = workspace 3, class:^(phi)$`. Popped-out panels share that class and have titles like
`Meters - PHI`, so you can place them separately, e.g. `windowrulev2 = monitor 1, title:^(Meters - PHI)$`. Plugin windows have the same class and titles like `MVerb - PHI`; a plugin you add opens straight away in its own window, and so does the Window button or `E` on a card. Plugin windows tile like any other window on Hyprland (one fills the space, the next splits it; add `windowrulev2 = float, title:^(.* - PHI)$` to float them instead) and are always resizable: drag them to any size or make one full screen. A plugin of fixed size is asked to draw itself bigger or smaller to fit (from half to four times its size; most JUCE-made CLAP and VST3 plugins, such as Dexed, can) and sits centred in what is left. With a plugin window focused (under the mouse on Hyprland), `Esc` or `Ctrl+W` closes it and the keys go back to the chain and `Ctrl+Tab` / `Ctrl+Shift+Tab` go to the next or previous plugin window; plugins drawn with their own toolkit may keep those keys, and then the card's Window button, `E` or your usual close key (Omarchy's `Super+W`) still work. If the desktop force-closes a plugin window, PHI keeps running; plugin windows then come back after a restart.
